= AIエージェントから本マニュアルを使用する

本マニュアルは、人間が読むだけでなく、AIコーディングエージェント
(Claude Code、Codex、Cursor、GitHub Copilotなど)
から直接利用できるように作成されています。
SC-OBC Module A1 を搭載するキャリアボードの設計、CubeSat向けFPGAロジックの開発、
Zephyr RTOSソフトウェアの作成などを行う際は、公開されたサイトを手作業で検索する代わりに、
マニュアルのソースリポジトリをクローンしてエージェントに参照させることができます。

[source, console]
----
git clone https://github.com/spacecubics/sc-docs-a1
----

リポジトリには、マニュアルの構成や、ハードウェア仕様、インターフェース表、
ソフトウェアのサンプルを探す場所をエージェントに伝える `AGENTS.md` ファイルが含まれています。
関連するセクションをエージェントに指定する必要はありません。たとえば、次のように質問するだけで、
エージェントが適切なページを見つけます。

* 「VIN_Aの推奨動作電圧の上限は？」
* 「FPGA起動前と起動後で、TRCHはそれぞれ何をしますか？」
* 「ZephyrでGPIOドライバを追加する方法は？」

同じ内容をブラウザで閲覧するには、公開版のマニュアル
https://docs.spacecubics.com/[docs.spacecubics.com] を参照してください。
